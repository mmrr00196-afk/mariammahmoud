RAG AI Assistant

AI-Powered Retrieval-Augmented Generation System using n8n

System Workflow Architecture:
📁 Google Drive Private Docs
➔
🧬 Embeddings Text Vectors
➔
🌲 Pinecone Vector Database
➔
⚡ n8n Agent Retrieval & Routing
➔
💬 Telegram Bot User Interface

An AI-powered RAG system designed to answer questions based on private documents and a dedicated knowledge base instead of relying only on the language model’s general knowledge.

Documents are received from Google Drive, processed into embeddings, and stored in Pinecone. When a user sends a question through Telegram, the AI Agent searches the knowledge base for relevant information and uses the retrieved context to generate a grounded response.

Anti-Hallucination Design: If the required information is not available in the knowledge base, the system can indicate that the information was not found instead of simply guessing.
